# Minecraft Clone
A Minecraft inspired game with procedurally generated terrain and structures.

## Features
- Procedurally generated terrain using simplex noise
- Toroidal (planetoid) worlds
- Multi threaded chunk generation
- Block interactions
- Transparent block textures
- Saving and loading system
- World seeding

## Tech Stack
- Engine: Unity, C#
